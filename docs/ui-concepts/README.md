## User requirements

- Design before GUI implementation.
- Initial new-map sizes: 400 and 500, using existing empty reference map bytes.
- Preserve original templates; edits stay in memory until explicit Save/Export.
- Deliver a portable single Windows executable without user-installed dependencies.
